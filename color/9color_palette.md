# 🎨 金燦粒子漩渦黑風格配色指南 (Gold Particle Vortex & Satin Gold)

本配色方案靈感取自 `color/9.JPG` (Gold Glitter Particle Vortex)。整體使用**螺旋金燦粒子陣列**搭配**絲緞金切角字體**，展現出歡慶、躍動與高能量資產累積意象。

```css
:root {
  --bg-obsidian-vortex: #0a0a0a;
  --color-particle-gold: #f4c430;
  --color-satin-gold: #f3c667;
  --gradient-satin: linear-gradient(135deg, #fff3d1 0%, #f3c667 50%, #b8860b 100%);
  --text-pure-white: #ffffff;
}
```

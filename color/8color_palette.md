# 🎨 3D 幾何菱形網格金風格配色指南 (3D Geometric Diamond Mesh Gold)

本配色方案靈感取自 `color/8.JPG` (Black Friday Diamond Mesh Gold)。整體使用**高光亮黃金與白手寫體 Accent**，搭配 **3D 立體金屬菱形浮雕背景**，創造出極強的立體空間感與高光視覺焦點。

```css
:root {
  --bg-mesh-black: #111111;
  --color-diamond-gold: #ffd700;
  --color-gold-shadow: #e6b800;
  --gradient-diamond: linear-gradient(180deg, #fff2a3 0%, #ffd700 60%, #997a00 100%);
  --text-script-white: #ffffff;
}
```

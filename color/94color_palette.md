# 🎨 極簡黑亮玻璃與金屬銀邊風格配色指南 (Dark Glossy Glass & Silver Edge Amber Gold)

本配色方案靈感取自 `color/94.jpg` (Glossy Black Login Panel)。使用**極致黑亮斜光鏡面玻璃**、**銀亮金屬邊框**與**琥珀金亮黃按鈕 (`#FFB800`)**，展現極強的高階登入面板與奢華質感。

```css
:root {
  --bg-matte-dark: #222222;
  --bg-glossy-card: #080808;
  --border-silver: #d1d5db;
  --color-amber-button: #ffb800;
  --text-white: #ffffff;
}
```

# 🎨 古銅鏡面黑金風格配色指南 (Mirror Metallic Bronze Gold Palette)

本配色方案靈感取自 `color/7.JPG` (Black Friday Mirror Gold)。整體設計使用**古銅黃金金屬光澤**配上**柔和咖啡黑暈光底色**，展現極具重金屬質感與尊榮奢華風範。

```css
:root {
  --bg-coffee-black: #1c1615;
  --color-metallic-gold: #f5b041;
  --color-bronze-dark: #7d5a29;
  --gradient-metallic: linear-gradient(135deg, #fff2d1 0%, #f5b041 45%, #7d5a29 100%);
  --text-white: #ffffff;
}
```

# 🎨 EWC 電競薄荷綠與熾熱亮橘風格配色指南 (Esports Mint Emerald & Flame Orange)

本配色方案靈感取自 `color/95.JPG` (EWC 電競世界盃轉播面板)。使用**薄荷翡翠綠背景 (`#00C896`)** 搭配 **熾熱火焰橘 (`#FF5500`)** 與 **純白賽程卡片 (`#FFFFFF`)**，展現極高能量的電競賽事與實況直播質感。

```css
:root {
  --bg-mint-emerald: #00c896;
  --color-flame-orange: #ff5500;
  --color-live-red: #ff0000;
  --bg-bracket-white: #ffffff;
  --text-dark: #111111;
}
```

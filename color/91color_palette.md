# 🎨 琥珀金橘發光外框霓虹風格配色指南 (Amber Gold Neon Glow)

本配色方案靈感取自 `color/91.JPG` (Amber Gold Neon Glow)。使用**琥珀金橘色的微光霓虹外框 (Glowing Backlight Outlines)** 襯托純黑字體，搭配**散落金燦火花粒子**，營造強烈的極光夜空與高壓電光視覺。

```css
:root {
  --bg-neon-dark: #0d0d0d;
  --color-amber-glow: #ff9900;
  --color-amber-light: #ffcc00;
  --text-dark-core: #0d0d0d;
  --glow-amber: 0 0 25px #ff9900, inset 0 0 10px #ffcc00;
}
```
